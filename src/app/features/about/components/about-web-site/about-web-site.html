Web Site Internals


This site is intended to be the home for Monaco Software Solutions on the Web but also a sandbox if you will for testing and working with new software development tools and technologies most of which are in the Microsoft Software Stack.    This Single-Page Web site/application was predominantly written in Angular 20 with an ASP.NET CORE MVC RESTful Web API backend which accesses a SQL Server database.   This Web site/application can now be used as a fully functioning template for building any Single-Page database driven Web applications for business use.   


Here is a quick summary of some of the features of this Web site/application:

  • • Angular 20 Single-Page Web Frontend
  • • ASP.NET CORE MVC RESTful Web API
  • • SQL Server Database
  • • Database driven User Authentication and Role based security.
  • • JSON Web Tokens (JWT) for Web API Authentication
  • • Database driven Menu system using Role based security.
  • • Google Analytics Integration.

Also here are some the tools and technologies used to create this Web site/application:

  • • Visual Studio 2022
  • • Visual Studio Code
  • • MS.NET C#
  • • Microsoft ASP.NET CORE MVC RESTful Web Services
  • • SQL Server Database
  • • Angular 20
  • • JSON
  • • CSS
  • • Bootstrap
